この旅について

出発地は47都道府県の県庁所在地（東京都は新宿）からランダムに選びます。道路・田畑・家・林・海は自動生成の風景です。実際の地形、建物の外観、通行可能な道路は再現していません。

右上は施設の実座標を使った旅の模式図です。点線は予定経路、実線は走行済み経路、丸は寄り道先。表示位置はシミュレーター内の現在位置で、端末のGPSは使いません。

およそ2〜4分の走行ごとに実在施設へ寄り道し、10秒ほど停車します。施設情報の鮮度や営業状況は確認していません。

通信できない場合も走行を続けます。同じ街で以前取得した施設があれば保存データを使用します。保存できない環境では、その旅の間だけ保持します。

出典：OpenPOI API / データ出典・ライセンス

表示した施設のデータと出典情報をブラウザ内に保存します。音声・外部ライブラリは使っていません。
